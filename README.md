# 🚀 CITYHOP – Smart Shared Mobility Platform

CITYHOP is a **real-time smart mobility platform** designed for **fixed-route shared transport** (tuk-tuks, e-rickshaws, campus shuttles).  
It enables **live tracking, dynamic seat availability, and intelligent passenger–driver matching** to make last-mile commuting faster, smarter, and more efficient.

---

## 📌 Problem

Shared transport systems today are highly inefficient due to lack of real-time coordination:

- ❌ Passengers don’t know **when a vehicle will arrive**
- ❌ No visibility of **available seats**
- ❌ Drivers don’t know **where passengers are waiting**
- ❌ Leads to **delays, overcrowding, and fuel inefficiency**

---

## 💡 Solution

CITYHOP introduces a **real-time connected ecosystem** where passengers and drivers interact dynamically:

- 📡 Continuous **live location sharing**
- 🧠 Intelligent **route + direction matching**
- 🚐 Support for **multi-passenger shared rides**
- 🔄 Real-time updates for **ETA & seat availability**

---

## 👤 Passenger App

- 📍 Select pickup location on map  
- 🎯 Enter destination & group size  
- 🚐 View nearby vehicles in real-time  
- ⏱️ Get ETA and seat availability  
- 🧭 Track approaching vehicle live  

---

## 🚖 Driver App

- 🛣️ Select predefined operating route  
- 📡 Broadcast real-time GPS location  
- 🔄 Share travel direction  
- 💺 Update available seats dynamically  

---

## 🧠 Smart Matching Engine

- 📌 Route-based matching  
- 🔁 Continuous real-time updates  
- 👥 Supports **mid-ride passenger onboarding**  
- 🗺️ Live interactive map visualization

## 🏗️ Tech Stack

- **Frontend:** React Native / Expo  
- **Backend:** Node.js / Firebase  
- **Database:** MongoDB / Firestore  
- **Realtime:** WebSockets / Firebase Realtime DB  
- **Maps & Location:** Google Maps API
